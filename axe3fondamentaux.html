Formule SDF

      

        -- Score de Distresse Fondamentale (SDF) ∈ [0, 1]

        -- Chaque composante normalisée : 0 = sain, 1 = distresse


        SDF = 0.35 × dette_EBITDA_norm

            + 0.25 × priceToBook_norm   -- faible P/B = distresse

            + 0.20 × liquidite_norm     -- inversé : faible curr_ratio = risque

            + 0.20 × earningsGrowth_norm -- négatif = déclin


        -- Normalisation dette/EBITDA :

        --   < 1×  → 0.0 (sain) | 1-3× → 0.5 (normal) | > 5× → 1.0 (distresse)

        -- Normalisation P/B :

        --   > 2.0 → 0.0 (sain) | 0.5-2 → 0.5 | < 0.3 → 1.0 (distresse)

        -- Normalisation Current Ratio :

        --   > 2.0 → 0.0 (liquide) | 1-2 → 0.5 | < 0.8 → 1.0 (illiquide)

        -- Normalisation Earnings Growth :

        --   > +10% → 0.0 | -10 à +10% → 0.5 | < -20% → 1.0 (déclin)
      

      
Références académiques

      

        Altman Z-Score (1968) — modèle de prédiction de faillite. Nos ratios dette/EBITDA et P/B en sont dérivés.

        Merton Distance to Default (1974) — valeur de l'entreprise vs dettes = distance à la faillite.

        Ohlson O-Score (1980) — 9 ratios comptables prédisant la défaillance. Notre SDF en est une version allégée.

        Piotroski F-Score (2000) — 9 signaux fondamentaux binaires sur santé financière.

        Novy-Marx (2013) — gross profitability predicts returns. Lié à notre earningsGrowth.

        Campbell-Hilscher-Szilagyi (2008) — modèle de distresse financière sur données comptables.
      

    


    

      
Limites méthodologiques

      

        1. Données trimestrielles : les fondamentaux Yahoo sont mis à jour tous les 3 mois (résultats). Le signal peut être retardé de 1-2 trimestres vs la détresse réelle.

        2. Point-in-time : en backtest, on ne peut pas utiliser les fondamentaux futurs. Cela crée un look-ahead bias si on utilise les données actuelles sur les trades passés. Hypothèse de travail : les fondamentaux sont stables sur 1 an.

        3. Secteurs différents : dette/EBITDA de 4× est normale pour un opérateur télécom (TF1), catastrophique pour un distributeur (Casino). SDF non normalisé par secteur = biais sectoriel.

        4. Yahoo quoteSummary disponibilité : les tickers SBF120 ne fournissent pas tous debtToEquity (holdings pures, SPACs, etc.). Fallback sur ret63 < -40% si SDF non calculable.

        5. N(distresse) attendu faible : si T44/T45 ont montré que z < -2.5 pré-sélectionne des titres homogènes, N(SDF > 0.65) pourrait rester < 10 → même problème de représentativité statistique.
