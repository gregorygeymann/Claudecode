🌞 Re-scan midi
🌞 Test Re-scan midi : les 3 premiers boutons envoient un faux Telegram avec banner 🌞 RE-SCAN MIDI HH:MM pour vérifier le rendu visuel. Le bouton "Lancer re-scan midi RÉEL" exécute runMiddayScan dans le worker (scan complet 72 tickers + analyse positions ouvertes), avec force=1 qui ignore le cooldown 4h. Cette option simule ce qui se passera à 12h00 Paris en cron.
⚠️ Note : un re-scan réel prend 30-60 secondes (2 sous-batches Yahoo) et envoie un Telegram si nouveaux signaux apparaissent par rapport au scan 8h00.
📌 Comment ça marche : le worker tourne automatiquement 2 fois par jour en semaine : à 8h00 Paris (scan matinal complet) puis à 12h00 Paris (re-scan midi pour capturer les signaux apparus en matinée et les TP/SL atteints intraday). Heure d'été et d'hiver gérées via DST.
Il envoie au plus un Telegram par fenêtre avec : 🟢 ACHATS (nouveaux signaux MR), 🟠 VENTES (positions à clôturer selon TP/SL/theta), 😴 CALME (rien à faire) ou ⛔ PANIC (régime K-means bloque les entrées). Les notifs midi affichent le banner 🌞 RE-SCAN MIDI HH:MM pour distinction visuelle.
Cooldown séparé : un signal notifié le matin n'est PAS re-notifié à midi (déduplication 7j). Un signal nouveau apparu en matinée (ex: gap d'ouverture) est notifié à midi (déduplication 4h).
Pour recevoir les recommandations VENTE, vous devez synchroniser vos positions ouvertes en cliquant sur le bouton ci-dessus. Le worker recalculera chaque jour avec les prix actualisés.

🥇 P1 — Impact +128% validé
VIX-INV amplitude extrême

🥈 P2 — +35% validé
2e compte courtier
Test 14 confirme : passer de 1 à 2 comptes (cap 60% chacun) capture 6 trades supplémentaires sur 5 ans — les plus rentables (jours de crise). Gain +35%, MDD inchangé.
Action : ouvrir compte Fortuneo/Saxo (30€ max de frais d'entrée). C'est le gain le plus facile à capturer.
🥉 P3 — +10% validé
Sectoriel proxy v2
Test 13 : proxy v2 (prix réels des peers, pas signaux MR) donne +10% robuste. 66 trades sectoriels (+10%) vs 89 idiosyncratiques (-30%). Activer à paramètres doux (×0.7/×1.1).
Action : déjà implémenté ✓. Surveiller le ratio idio/sect en live (cible ≤30% idio).
⚠️ P4 — À surveiller
NLP GPT-4o-mini
Test 9 : Groq -40%, GPT-4o-mini -2%, GPT-4o +12%. Le seuil de rentabilité NLP est 70% d'accuracy. GPT-4o-mini à 72% est marginalement rentable (+2%). GPT-4o à 75% donne +12% clair.

🔬 P5 — Nouvelle piste
Intraday scanning 9h30 / 12h

Coût : données intraday IEX Cloud ~50€/mois. ROI estimé +15-25% sur les Flash uniquement.
❌ À désactiver
